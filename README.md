# Enemy AI Survival

A 2D top-down survival game built with Unity and C#.

## Features

- Player movement
- Mouse-directed shooting
- Enemy AI with idle, chase, and attack behavior
- Obstacle-aware enemy movement using raycasts
- Enemy health bars
- Damage and hit feedback
- Knockback mechanics
- Wave-based enemy spawning
- Score system
- Player health and game-over system
- Restart functionality
- Main menu

## Technologies

- Unity 6
- C#
- 2D Physics
- Unity UI / TextMesh Pro
- Git / GitHub

## How to Run

1. Open the project in Unity Hub.
2. Open the `MainMenu` scene.
3. Press Play.
4. Select `PLAY` to start the game.

## Controls

- WASD / Arrow Keys — Move
- Left Mouse Button — Shoot
- Mouse — Aim

## Gameplay

Survive increasingly difficult waves of enemies and eliminate zombies to increase your score.
